## 服务器操作

在 `/opt/apaas/apaas-sales360-crm` 下执行：

```bash
docker compose --env-file .env -f deploy/compose.production.yaml ps
sh deploy/backup-production.sh
docker compose --env-file .env -f deploy/compose.production.yaml up -d
```

备份保存在本仓库忽略提交的 `backups/`，每次升级前执行并将备份复制到独立存储。升级时先确认目标 GHCR 镜像可拉取，再更新服务器 `.env` 的 `API_IMAGE`，执行备份与 Compose 更新，随后验证健康、登录、业务读写及权限。不要删除数据库卷。

当前共用的 Caddy 网关属于服务器上的其他项目。该项目的下一次发布可能替换当前配置；发布前须把 `/apaas-sales360/*` 转发规则同步至新版本网关文件，发布后复测本应用和原有服务的健康接口。
