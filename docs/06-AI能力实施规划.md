# AI 能力与数据边界

Sales 360 CRM 的 AI 助手由使用者在 API 容器配置 `OPENAI_API_KEY`、`OPENAI_MODEL` 与可选 `OPENAI_BASE_URL`。服务端调用兼容 OpenAI Responses API 的模型；模型未配置时，核心业务和本地账号照常工作，AI 入口显示未启用。

对话按工作区和当前用户隔离并支持删除。业务上下文由后端按现有角色权限读取，不接受浏览器自行指定越权数据。结构化建议只供人工复核，不自动改变业务单据或主数据。客户、物料和单据上下文可能发送给所配置的模型服务；部署者应自行选择服务商并确认数据处理要求。模型密钥不能提交到 Git，也不能写进前端或 Cloudflare Worker。
