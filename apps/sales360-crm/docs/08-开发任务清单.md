# 开发任务清单

此文件保留开发前的分阶段计划；当前完成项、测试结果和未接入能力以 [`09-实施与验收记录.md`](09-实施与验收记录.md) 为准。

按依赖顺序执行；每项都有完成证据。本文是后续实施清单，勾选前必须检查代码、数据库与真实用户路径。

## M0 可运行基座

- [ ] 创建 `frontend/`、`backend/`、`infra/`，锁定依赖版本，提交开发启动命令与 `.env.example`。
- [ ] PostgreSQL 迁移、健康检查、请求 ID、统一错误、日志脱敏。
- [ ] 系统登录、组织/角色/成员与服务端租户隔离；至少四种验收角色可创建。
- [ ] 前端设计变量、桌面/手机布局骨架、登录与无权限页面。
- 完成证据：新环境按 README 启动，创建账号登录；重启后会话和数据行为符合设计，越权 API 被拒绝。

## M1 线索闭环

- [ ] 线索创建/查询/筛选、重复候选、详情与时间线。
- [ ] 人工与自动分配、接受/退回/无效、轮转策略、并发冲突。
- [ ] 有效判定、申请转化、主管审核与拒绝原因。
- [ ] 移动端与桌面端的列表、详情、表单和错误状态。
- 完成证据：运营→销售→主管不同账号完成全部路径，分配与状态事件可查，刷新后状态保持。

## M2 客户与商机

- [ ] 客户/联系人管理及负责人转移。
- [ ] 线索事务性转化、重复提交幂等、客户去重候选。
- [ ] 商机创建、参与人、阶段推进、赢/输单和跟进记录。
- 完成证据：转化后源线索和目标记录关联一致；并发提交无重复；金额与权限正确。

## M3 工作台与通知

- [ ] 应用内待办、到期跟进、通知 outbox 与失败重试。
- [ ] 工作台、团队处理率与商机统计，展示统计口径。
- [ ] 核心端到端测试、移动/桌面视觉验收、备份恢复步骤。
- 完成证据：业务动作使工作台真实更新；通知失败可查且不伪称送达；数据库恢复演练通过。

## M4 平台接入（逐平台验收）

- [ ] 飞书：管理员授权、登录、成员同步、消息/待办；记录权限、接口限制和端到端结果。
- [ ] 钉钉：同上，独立适配器与验收报告。
- [ ] 企业微信：同上，独立适配器与验收报告。
- 完成证据：在对应客户端真实收到与打开业务记录，撤权和失败路径也验证。未完成的平台保持“未接入”。

## M5 CSM 扩展

- [ ] 服务计划、任务、风险、续约商机、客户服务报表及权限。
- 完成证据：从客户到服务任务、风险处理和续约有完整的数据库与角色流转记录。
